# FORMULARIO-FORMS-ME-


Um formulário interativo corporativo desenvolvido com foco em alta performance, usabilidade (UX/UI) e regras de negócio condicionais. Projeto construído para simular um motor de recrutamento e triagem técnica para vagas na área de Tecnologia da Informação.

---

## 📱 Recursos e Diferenciais

- **Interface Corporativa Modernizada:** Desenvolvida com **Tailwind CSS** e tipografia **Inter**, garantindo uma experiência visual alinhada com os padrões de produtos SaaS do mercado.
- **Campos Condicionais Dinâmicos:** Exibição inteligente de perguntas com base nas respostas fornecidas (ex.: tempo de experiência em ecossistema Python e quantidade de dependentes).
- **Indicador de Progresso em Tempo Real:** Barra de progresso visual que se ajusta automaticamente à medida que o utilizador preenche o formulário.
- **Backend-Ready:** Arquitetura estruturada para consumo e integração com APIs REST em **Java (Spring Boot)** ou **Python (FastAPI)**, além de integração direta com serviços de envio como o Web3Forms.
- **Design Responsivo & Acessível:** Interface totalmente adaptada para dispositivos móveis, tablets e computadores de secretária.

---

## 🛠️ Tecnologias Utilizadas

* **Frontend:** HTML5 Semântico, Tailwind CSS (CDN), JavaScript (Vanilla ES6+)
* **Backend Target:** Java (Spring Boot) / Python (FastAPI)
* **Integração & Protocolos:** REST APIs / JSON Schema
